Как считается

  • Зеркало = объём писем + {{ (coef.DOVECOT_OVERHEAD * 100) | round | int }}% на индексы Dovecot + в среднем полблока файловой системы ({{ coef.FS_BLOCK // 2 }} байт) на письмо — в Maildir каждое письмо отдельный файл.
  • restic ≈ {{ (coef.RESTIC_RATIO * 100) | round | int }}% от объёма писем: текст сжимается хорошо, вложения (PDF, фото, архивы) — почти нет. Следующие снимки добавляют только новые письма.
  • Рекомендуемый диск = (зеркало + restic) × {{ coef.GROWTH_RESERVE }}: запас на рост ящиков и на удалённые на хостере письма — по умолчанию из бэкапа они не удаляются.
  • Это оценка до первого бэкапа. Реальный размер появится после бэкапа и снимков restic.
